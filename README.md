# karemdm.github.io
Personal portfolio in English (index.html, default) and Brazilian Portuguese (pt/index.html) for Karem Daiane Marcomini, Ph.D., built for GitHub Pages: hero, about, skills, experience, featured projects, education and teaching.
Self-contained inline CSS (IBM Plex type, light theme by default with an optional dark theme switch, no frameworks), responsive down to 360px; content comes from the GitHub profile README and project metadata. Prepared with AI assistance.
